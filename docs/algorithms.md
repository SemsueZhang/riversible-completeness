## 四种方法

### FL2025：原文 Theorem 2 / Proposition 3 的构造

2026-10-22 按用户要求替换原来的局部网格运输重构。当前 `fl2025` 对应 arXiv:2508.17273v2 的 Section IV：先用 Theorem 2 路径化，再用 Proposition 3 和 Lemmas 4–5 归约为范式。方法名仍为 `fl2025`，旧版重构与当前版本的规则次数不能混为同一个基线。

路径化实现位于 `src/fl2025.cpp`，完整电路的两遍处理入口位于 `src/routing.cpp`，范式分派入口位于 `src/path.cpp`。生产范式实现位于 `src/indexed_path.cpp`，保留 FL 的独立 Lemmas 4–5 调度；`src/fl2025.cpp` 中的向量实现保留为参考。

1. 对整个输入电路应用原 Rule 2，补齐控制，得到全控制门序列；再逐门执行路径化。
2. 对交换 Hamilton 路径节点 `a_i, a_j` 的非路径门 M，构造原文规定的回文字 `M_i ... M_(j-1) M_(j-2) ... M_i`。程序先推导该回文字到 M，最后反向使用此推导，得到 M 到路径字。
3. 按 Theorem 2 选择重复坐标 `m_g = m_h`，中间坐标彼此不同且不等于该坐标。先用 Lemma 3 翻转后缀回文，再按 Rule 3 移动左右两侧对应的门块，得到原文式 (1)。
4. 再用 Lemma 3 调整中央回文。用原文派生 Rules 7/9 的 X 门移动进行极性调整，然后对完整模板应用一次原 **多元素 Rule 5**，得到式 (2)。它不是把一段多元素替换拆成多次单元素替换。
5. 撤销极性调整，用 Lemma 3 得到式 (3)，更新坐标序列并重复，直到只剩目标门 M。不会调用 `grid_route`，也不会通过先求范式再反向展开来对齐路径字。
6. 范式阶段单独实现 Proposition 3：依次处理最小路径门下标，按 Lemma 4 消去重复出现，再按 Lemma 5 抽出递增块。使用原文的简单情形 (i)、(ii) 和 Cases 1–4，不调用 FXL 的 `extract_block` 调度。

**确定性选择与适用前提：**原文没有指定唯一 Hamilton 路径、坐标对优先级或所有局部交换顺序。本实现沿用反射 Gray Hamilton 路径；Rule 2 按线路下标升序展开。坐标对在满足原文条件、且删除后仍保持简单边链的候选中，优先选择较大的 `|Q|`，并以左端点位置打破平局。保持简单边链用于确保后续 Lemmas 1/3 的前提，因此该调度不会产生需要另行删除的相邻重复坐标。每次 Lemma 3 调用也显式检查相邻门的共同控制极性及非相邻门的相反控制条件；找不到满足前提的坐标对时明确报错，不回退到其他路径化方法。这个选择规则是本实现补足的确定性调度，不声称是作者唯一指定或最优的调度，已运行有限样本性能测试，尚未做独立语义验证。

块消去时选择当前下标最左侧的两个相邻出现位置。先处理 Lemma 4 的两种简单情形，否则按左侧递增链应用四种情形；Case 1 优先消去最左的相邻相同门，Case 4 的门逐个向左移动后转入 Case 3。X 极性调整按线路下标升序执行。

**计数口径：**只计原基本 Rules 1–5。Rule 2 的每次一位控制细分、每次 Rule 1 配对增删、每次 Rule 3 相邻交换均计一次；无论 `|Q|` 多大，一次合法的 Rule 5 整段替换计一次。派生 Rules 7/9、Lemma 2 的 braid 和 Lemma 3 的回文翻转都通过基本规则展开计数。派生极性变化的底层证明仍可使用 `|Q|=1` 的 Rule 5；这与 Theorem 2 中对多元素模板整体计一次是不同层次。不同位置复用缓存推导也累加全部基本次数；模板构造、坐标对选择和缓存开销均属于实测时间。

这次修正实现了原文构造路线，仍需区分“完成源码与编译”与“运行正确性已经验证”。随后已运行 FL/FXL 二值范式归约性能测试，见[报告](../results/fl-fxl-binary-20261022/report.md)，未执行独立正确性验证；本实现也不是作者发布的软件。

### FXL2026：二值递归路径化和块消去

主入口为 `src/fxl2026.cpp` 的 `Compiler::fxl_route`。

- 根据 Proposition 3 与 Algorithm 1，用低目标线路上的无条件 X 门将全控制门共轭到路径代表。
- 非全控制门先用 Rule 2 展开；辅助 X 门按文中 Gray 次序优化排列，排序中的 Rule 3 也计数。
- 每轮处理上一轮的门序列，再消去相邻辅助 X 门，直到所有门均为路径门。
- 新 Rule 5 按原文左右相同 X 次序生成；如果局部模板需要逆序右共轭字，额外交换会计数。
- 最后执行 Algorithms 2–4。Algorithm 3 使用从左到右的 redex 优先次序，补齐空块和数组边界处理。

只允许 `d=2`，不使用该论文关于辅助位和垃圾输出的 RC+ 规则。

### NF：本文第三节

主入口为 `src/nf.cpp` 的 `Compiler::coordinated`，总体线路下降调度在 `src/routing.cpp` 的 `Compiler::route`。

- Rule 2 按反射 Gray 次序补全控制。
- 用 Rule 8 将全控制门运输到保持相同目标、相同更高线路控制值的路径门。
- 显式归约共轭字，并在递归展开前消去暴露的辅助门。
- 按目标线路从高到低展开，低线路辅助门不会重新引入高目标门。
- 最后用 FXL Algorithms 2–4 的块消去结构归约；路径 braid 通过本文 Lemma 2 的证明展开为 MRC^r 基本规则。

使用 Rules 1–8，不将本文第四节的 Rules 9–11 当作免费基本操作。

### DC：本文第四节

主入口为 `src/dc.cpp` 的 `Compiler::cancel_path`，网格运输在 `src/routing.cpp`。

- Rule 2 补全控制。
- 按 Lemmas 4–5 沿较低维反射路径逐格运输。
- 每个网格步骤实际展开 Rule 11、Rule 2、交换和配对消去。
- 对路径字执行 Algorithm 2 的四种递增链更新。Rules 9、10 在该规则系统中各算一个基本步骤。
- 如果某一轮结束仍有非空链，则当前字不是恒等置换。程序返回不相等，不会丢弃这条链。

等价性入口先分别路径化 A、B，再消去 `A' reverse(B')`。对于正例，最终总数包含将判等过程转为 `A -> B` 所需的 `|B'|` 个配对插入。

## DC 的范式适配

第四节没有独立提出“从任意电路输出范式”的算法。因此 `bench_normalize --algorithm dc` 明确采用以下适配：

1. 对输入 C 做 DC 路径化，得到 C'。
2. 计算 C 的函数表，并按 PDF 的 Algorithm 1 构造唯一范式 F。
3. 用直接消去处理 `C' reverse(F)`。
4. 将 `|F|` 次配对插入计入总数，得到 `C -> F` 的规则数。

这四步的计算时间全部纳入计时。第 2 步的函数表操作和插入排序不属于规则应用，不计入规则数。它是 DC 的范式适配器，不应在论文里写成第四节原生范式算法。

## 共用设施

- `src/compiler.cpp`：局部规则展开、基本次数累加、可复用端点摘要。
- `src/path.cpp`：将 FL/FXL 分派到索引实现；保留原 FXL/NF 向量调度及供 DC 范式适配、测试验证使用的函数表插入构造。
- `src/indexed_path.cpp`：FL Lemmas 4–5 与 FXL Algorithms 2–4 的各自调度，按相同最左优先级执行；以索引代替重复全表扫描。
- `src/core.cpp`：门语义、反射 Gray 路径、字替换、溢出和资源检查。
- `src/experiments.cpp`：两类任务的组合方式。

内部只保存模板的起止字、总次数和资源检查所需的局部峰值，不保存或输出逐步证书。模板反向使用保持同一总次数。局部模板仍使用可变向量，但等长替换已原位执行。FL/FXL 范式阶段使用整数门编号、存活链和紧凑位置索引，维持同一重写顺序；模板缓存有明确上限，不保存推导历史。实际时间仍包含当前状态维护、模板查找及端点匹配，不能直接当作论文抽象 RAM 模型的常数。
