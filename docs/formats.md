# 输入与输出格式

## CAT 1

```text
CAT 1 3 2
# d=3, n=2. Controls are listed for lines 0,1.
G 0 0 * 2
G 1 1 0 *
END
```

头为 `CAT 1 d n`。每行 `G t i c0 ... c(n-1)` 表示本文 `G[alpha,t,i]`：目标线 t 交换相邻取值 i、i+1，控制值 `*` 表示不控制。目标位置必须为 `*`。门从上至下、即从左至右执行。

允许空电路（头之后直接 END）。`#` 之后为注释。文件必须有 END，END 后不得有有效内容。

输入解析器接受 `2 <= d <= 1024`、`1 <= n <= 64`，单文件最多 1,000,000 门；实际可处理规模另受 `d^n` 等运行限制约束。

## RevLib REAL

支持 `.version 1.0/2.0`、`.numvars`、`.variables`、`.inputs`、`.outputs`、`.constants`、`.garbage`、`.begin`、`.end` 和 `tN` 门。

`tN` 的最后一个变量是目标，前面的变量是控制，默认控制值为 1。额外支持 `-a` 或 `a'` 表示负控制（控制值 0）。不允许负目标或重复变量。

`.inputs/.outputs` 作为标签读取，不用于自动推断线路置换；线路身份由 `.variables` 的顺序确定。比较不同命名或重排线路的两个文件时，需要显式统一其线路对应关系。

当前只接受所有 `.constants/.garbage` 标记均为 `-` 的文件；不支持量子门、模块调用、Fredkin/Peres 原生门或受限输入等价。RevLib 中采用 MCT 分解的 Fredkin 电路可以直接读取。

## 线路排序

两个基准入口默认采用 `--wire-order target-frequency`：统计每条线路作为输入门目标的次数，按次数降序分配新下标 0～n−1；次数相同则保留原线路顺序。这精确最小化全部输入门的目标下标之和。使用 `--wire-order original` 可保留输入的线路编号。

`wire_map[k]` 表示原第 k 条线路的新下标；每个门的目标和所有控制位置同时重映射，取值和门序不变。同一输入在所有方法和重复轮次中使用同一排列，不修改原始数据文件。

如果次数 f < g 的两条线路分别位于 i < j，互换可将目标下标之和减少 (g−f)(j−i)，因此按次数降序达到全局最小。该结论只针对输入门的目标下标之和，不保证规则总数或运行时间最小。相同次数按原顺序打破平局，也不构成任意线路改名下的唯一规范编号。

判等时合并统计两侧输入门的目标次数，最小化两侧之和，并对两侧使用同一排列；分别独立排序会破坏线路对应关系。输入本身的线路对应关系仍须事先统一。该操作选择算法使用的坐标和对应范式，不插入物理 SWAP 门。统计、排序与重映射计入算法时间，不计为基本规则应用；如将中间电路导回原线路，应使用逆映射。

## 清单

范式清单每行一个电路路径：

```text
case_0_a.cat
case_1_a.cat
```

判等清单每行三个字段，用真正的制表符分隔：

```text
case_0_a.cat	case_0_equal.cat	true
case_0_a.cat	case_0_unequal.cat	false
```

这里展示的分隔为制表符。第三列可为 `true`、`false`、`?`；`?` 表示不提供预期结果。所有相对路径都相对于清单文件目录解析，绝对路径也可使用。空行和以 `#` 开头的行跳过。

## 生成器

种子驱动 `std::mt19937_64`，使用显式拒绝采样代替依赖标准库实现的 `uniform_int_distribution`，固定本版本生成序列。

每个基础电路 A 随机选择目标、相邻取值和部分控制。B 通过插入相消门对、控制补全、控制值归一化共轭、合法冲突控制交换得到，故与 A 相等。若编辑后字面不变，额外插入一对门，保证 A、B 文件不是同一个字。

负例从 B 末尾附加一个全控制的相邻换位得到。该门是非恒等置换，而 B 是双射，因此负例必不等于 A，不需要运行待测算法来生成标签。

这些数据属于人工构造数据，不应称作公开应用基准或任意可逆函数的均匀采样。当前版本的相等变换以补全、共轭、相消、交换为主；原始应用电路另外取自 RevLib。

## CSV

每行只输出两个性能指标：`rule_count,time_ms`。样本路径用标准 CSV 引号转义。`repeat` 从 0 开始。

默认在原有八列后附加标识字段 `wire_order,wire_map`，其中 `wire_order` 为 `target-frequency`。`wire_map` 是带 CSV 引号转义的 JSON 整数数组，例如 `"[2,0,1]"`；输入错误或方法不适用时可为空。使用 `--wire-order original` 时保持原有八列格式。
